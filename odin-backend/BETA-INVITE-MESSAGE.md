# Beta tester invite message

Copy/paste template for inviting someone to beta test Odin. Fill in
the bracketed name, then send as-is via text, email, or DM.

---

Hi [Name],

I'm reaching out to ask if you'd be willing to help beta test Odin, a
personal AI assistant I've been building for my home lab.

Getting set up takes about five minutes: you'll need the free Tailscale
app (this is what allows secure, private access — nothing about this
setup is exposed to the open internet), and I'll send you a link along
with your own personal access token.

As a tester, you'll be able to chat with Odin directly and view a
read-only summary of some trade-tracking data. Nothing else on the
system is accessible to testers — that boundary is intentional.

If you're willing to take part, let me know and I'll follow up with a
short setup guide and your credentials.

Thank you — genuinely. Volunteering your time to help find what's broken
before it matters is no small thing, and I'm deeply grateful for it.

[Your name]

---

**Once they say yes:** generate their token and send them the actual
setup guide (`BETA-TESTER-GUIDE.md`) along with their URL and token — see
`BETA-TESTERS.md` for the full add process. This message is the initial
ask, not the onboarding itself.
